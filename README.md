# Ducky 🦆 — застосунок для кухні та закупівель

Самостійний проєкт. Мова інтерфейсу: українська. Валюта: ₴.
Стиль: каченячий (кря, ставок, каченята) у тексті й дизайні, але без шкоди зручності.

## Функції
1. **Комора («Ставок запасів»)** — додавання продуктів вручну або зі скану чека (OCR/AI): назва, кількість, ціна, магазин, дата, термін придатності.
2. **Рецепти** — з наявних продуктів, з урахуванням техніки (мультиварка, хлібопічка), алергій, вподобань і порцій.
3. **Меню на тиждень** — план на 7 днів у межах тижневого бюджету та автоматичний список покупок.
4. **Аналіз цін по магазинах** — де що вигідніше купувати (Сільпо, АТБ, Novus, Фора, ринок).

## Правила
- Не вигадувати ціни й запаси: тільки дані користувача та чеків.
- Читати `docs/` перед великими змінами.
- Бюджет на їжу задає користувач (тижневий, у ₴).

## Дані користувача (docs/)
- `docs/kitchen-equipment.md` — техніка
- `docs/preferences.md` — алергії, вподобання, порції
- `docs/stores.md` — магазини та ціни
