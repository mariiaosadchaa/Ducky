# Дизайн Ducky: «Нічне золото»

Обрано напрямок A. Дві теми: темна (основна) і світла.

## Шрифти
- Заголовки: Cormorant Garamond (400–600, курсив для акцентів)
- Текст, меню, кнопки: Jost (300–500)
- Меню й кнопки: великі літери, розрядка 0.22em

## Кольори
| Роль | Темна | Світла |
|---|---|---|
| Фон | #0b1220 | #f7f1e3 |
| Текст | #efe6d2 | #0b1220 |
| Другорядний текст | #a9a291 | #55596a |
| Золото (акцент) | #d9bf8c | #7d5e25 |
| Лінії | #2a2f3d | #ddd2b8 |
| Кнопка | фон #d9bf8c, текст #0b1220 | фон #0b1220, текст #f7f1e3 |

## Принципи
- Тонкі лінії замість тіней, багато повітря, римські цифри для розділів.
- Логотип: качка в колі, лінія 1.4 px, колір акценту.
- Без вигаданих даних: у макетах лише позначки [Продукт], [сума] ₴.
- Макети: полотно Design «Ducky — люксові дизайни» (артборди Main та MainLight).

## Екрани (сайт 1280×800, телефон 390×844)
Кожен екран є в темній і світлій темі. Тема перемикається одним параметром `theme` (dark / light).

Навігація: Комора, Скан чека, Рецепти, Меню, Магазини. На телефоні це нижня панель вкладок (Комора, Чек, Рецепти, Меню, Ціни), активна вкладка підсвічена золотом і має лінію зверху.

| Екран | Вміст |
|---|---|
| Комора | Таблиця продуктів (продукт, кількість, магазин, придатний до), блок «Скоро зіпсуються», підказка, що приготувати першим |
| Скан чека | Зона завантаження фото, розпізнані магазин, дата, позиції, сума, кнопка «Додати в комору» |
| Рецепти | Фільтри (Усі, Мультиварка, Хлібопічка, Без покупок), картки: техніка, час, порції, що є вдома, що докупити (0–2), вартість |
| Меню на тиждень | Сітка 7 днів × 3 прийоми їжі, список покупок за відділами, сума з бюджету |
| Магазини | Таблиця Сільпо / АТБ / Novus / Фора за категоріями, де вигідніше, можлива економія |

Дані в макетах позначені [у дужках], бо реальні значення мають братися лише з чеків і вводу користувача.
